# Take N' Toke — redesign preview

Design preview of a full redesign of [takentoke.com](https://takentoke.com/) (Take N' Toke Dispensary, 994 Atlantic Ave,
Brooklyn, NY 11238), rebuilt on The Travel Agency's information architecture.

**Preview:** https://sgen-sites.github.io/takentoke-preview/

- Every page carries `<meta name="robots" content="noindex, nofollow">`: this preview is not for search engines.
- The live menu and product carousels are the client's own Dutchie embed; cart and ordering stay on the client's menu.
- Static site (HTML + CSS + vanilla JS). Generated imagery provenance is kept with the build source, not here.

Design preview, not the live site.
