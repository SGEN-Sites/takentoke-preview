Access / This Website

Website accessibility.

We aim to make this website easy to use for everyone: with a keyboard, a screen reader, a phone, or with motion turned off. This page describes this website only.

Call (718) 757-0094 Email us

On a keyboard? Press Tab once: the first stop on every page is the “Skip to content” link.

What this website does

What this website does.

System 01

Keyboard navigation

We aim for every link, button and menu to work from the keyboard. The main menus open with Space or the down arrow, Escape closes them, and the mobile menu keeps focus inside while it is open.

System 02

Visible focus

A bright cyan outline shows where you are whenever you move through a page with the keyboard.

System 03

Skip link

The first Tab press on every page reveals a “Skip to content” link that jumps past the header straight to the main content.

System 04

Reduced motion

If your device asks for reduced motion, the site switches off its animations, scroll effects and the moving starfield, and background videos stay paused.

System 05

Alt text

Images that carry information have text alternatives. Purely decorative images and floating objects are hidden from screen readers.

System 06

Quiet, pausable video

Background videos are decorative loops with no speech or information in them, so they carry no captions. They always play muted and pause when scrolled out of view. We aim to give every large background video a pause button: the homepage hero has one, and so does this page.

System 07

Color contrast

We aim for text that meets the WCAG 2.1 AA contrast guideline: near-white type on deep midnight, with lime and cyan reserved for labels and actions.

System 08

Clear structure

Each page has one main heading, landmarks for the header, navigation, main content and footer, and breadcrumbs on most inner pages. Questions and answers use native expand-and-collapse controls.

System 09

Age check dialog

The 21+ age check is a real dialog: focus moves into it and stays there until you answer.
